# Website

Static Astro app generated from the catalog. Run root `npm run dev` or `npm run build`. The site base path is `/github-showcase/`. Search matches names, aliases and extensions; filters combine category, runtime/viewer, and evidence. Filter state is shareable in the URL. All detail pages are static and work without JavaScript.

The site never executes examples. Source links point at the repository default branch; downloaded evidence records fingerprints for the specific build.
