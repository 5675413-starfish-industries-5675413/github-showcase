# Security policy

Do not put credentials or exploit details in public issues. Use GitHub private vulnerability reporting if enabled, or contact the repository owner privately. Private vulnerability reporting availability has not yet been verified.

The website is static and does not execute examples. Core execution uses a reviewed allowlist with process timeouts and output limits. It is not a sandbox for arbitrary submissions. CI runs contributor code with read-only repository access and no publishing credentials. Specialized/untrusted toolchains require separately reviewed isolation.
