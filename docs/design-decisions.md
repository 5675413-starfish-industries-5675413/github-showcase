# Explorer design reference lock

Audience: developers and learners inspecting examples and evidence. Direct build of the repository browser described in the blueprint.

Primary reference: Refero, Hugging Face “community meets workbench” (73870d92-fdc2-4e42-8e44-052d51346845): white canvas, cool gray structure, compact resource rows, monospaced resource names. Secondary: shadcn “components as the canvas” (200b455f-0b23-459c-99dc-421439de886b): compact neutral controls and clear focus states. Screen research: GitHub organization catalog and Cohere dataset filtering/empty states.

| Decision | Source | Role |
| --- | --- | --- |
| White canvas, gray rules, dense catalog | Hugging Face directory | Content browsing |
| Monospace names and identifiers | Hugging Face | Technical identifiers only |
| Neutral compact buttons | shadcn | Controls, not decoration |
| Sidebar filters and visible result counts | Catalog screen research | Discovery and recovery |
| Green on passing results only | Evidence semantics from brief | Positive verification state |
| Real code and actual catalog counts | User blueprint | Product proof; no stock imagery needed |

No decorative hero art, synthetic activity, or invented completion badges. A complete catalog with visible gaps is the distinctive product feature.
