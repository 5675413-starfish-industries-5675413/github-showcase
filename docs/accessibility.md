# Accessibility

The explorer uses native labeled form controls, keyboard focus rings, a skip link, semantic headings, text status labels, and an aria-live result count. Search can be focused with `/`. Filters reset explicitly. Static detail pages and the full initial index remain readable without JavaScript.

Responsive checks target desktop and a narrow mobile viewport. Automated or manual checks do not establish complete WCAG conformance; screen-reader and broader assistive-technology testing remain future work.

Local browser check: search + evidence combination, empty result and reset, category selection, language detail, and format collection passed. At a requested 390px mobile viewport, the measured layout and scroll width were both 375px (browser scrollbar excluded). Broad screen-reader testing remains unverified.
