# Platform feature matrix

The machine-readable `catalog/features` records provide configuration paths, prerequisites, actual evidence links, reviewed date and limitations. They are rendered directly in the website gallery.

Implemented files cover core/extended/detection CI, upstream proposals, reusable setup, devcontainer, offline core container, scoped CodeQL, dependency updates, Pages, releases, API access and signed webhook verification. Hosted settings cover Discussions, issues/labels/milestone, template reuse and the Verified main ruleset. Projects remain blocked by missing account scope; genuine human review remains a human action. A locally tested webhook verifier is not represented as a hosted webhook subscription.
