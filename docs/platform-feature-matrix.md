# Platform feature matrix

The machine-readable [feature records](../catalog/features) distinguish configured from demonstrated. Current files cover CI, Pages, releases, Dependabot, issue templates, PR template, code ownership, and a development container. Hosted runs and account-specific features are pending until linked evidence is recorded.

Optional integrations, container registry publishing, Projects, rulesets, Discussions, advanced scanning, and a full issue-to-release walkthrough are intentionally not claimed as implemented demonstrations.
