# Scope

The checked-in Linguist revision defines the language inventory. It is not all languages or file formats ever created. Format scope is eight initial targets: JSON, CSV, SVG, PCM WAV, ZIP, gzip, SQLite, and WebVTT. PDF, office formats, raster media, video, and 3D formats are future additions requiring appropriate examples and validation.

Platform scope includes repository collaboration files, core CI, dependency maintenance, Pages, and release artifacts. Advanced security, Projects, Discussions, webhook deployment, package publishing, and Codespaces usage require separate setup or demonstration. No arbitrary execution service is offered.
