# Scope

The checked-in Linguist revision defines 845 language entries across programming, markup, data and prose. All have examples. The corpus includes attributed syntax fixtures and original native/greeting examples. Fourteen languages have maintained execution checks; the others retain explicit runtime limitations rather than fabricated success.

The curated 24-format set covers documents (PDF/RTF), structured data (JSON/CSV/XML/TOML), spreadsheets (XLSX), databases (SQLite), images (SVG/PNG/GIF), audio (PCM WAV), video (H.264 MP4), subtitles (WebVTT/SubRip), 3D data (OBJ/glTF), archives (ZIP/TAR), compression (gzip/bzip2/XZ), and encodings (Base64/UTF-16LE). glTF demonstrates a named scene node; OBJ demonstrates a triangle. This is not every file format ever created.

Platform scope includes repository presentation, collaboration files, issues/labels/milestone, Discussions, required-check ruleset, security/dependency workflows, core/extended/detection/container CI, upstream proposals, Pages, versioned report artifacts, API/webhook demonstrations, reusable setup and development containers. Project creation is blocked by missing account scope. A human review and an actual Codespaces session are not claimed. No arbitrary code execution service is offered.
