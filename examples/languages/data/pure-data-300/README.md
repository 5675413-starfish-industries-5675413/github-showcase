# Pure Data

A minimal native document demonstrating the format. A text editor can inspect its structure.

Open `hello.pd` to inspect the authored source. The catalog makes no compile/run or full standards-conformance claim without matching evidence.

From the repository root, after installing the pinned Ruby bundle:

```sh
npm run linguist:audit -- pure-data-300
```

Expected classifier: **Pure Data**. Detection reads source as data. This inspection profile does not install a language compiler or execute the sample. For runtime work, use the language's compiler/interpreter and any referenced framework; no external environment is silently provisioned.
